# AutoReview — Курсовой проект

Полноценный сайт обзоров автомобилей, разработанный на чистом PHP с применением архитектуры MVC.

## Технологии
- PHP 8.1+ (нативный, без фреймворков)
- SQLite (встроенная БД)
- MVC-архитектура (Models, Views, Controllers)
- Сессии, хеширование паролей, подготовленные запросы
- CSS3 (тёмная тема, адаптивность, анимации)

## Структура проекта
server_web/
├── index.php # Точка входа
├── routes.php # Маршрутизатор
├── css/style.css # Стили
├── src/
│ ├── Controllers/ # Контроллеры
│ ├── Models/ # Модели данных
│ ├── Services/ # Сервисы (БД)
│ ├── Templates/ # Шаблоны (header/footer)
│ └── Views/ # Представления
└── public/images/ # Изображения авто
